# krish-a · маркетплейс новостроек + кредитный брокер

Аналог Krisha для новостроек с ролевой моделью и онлайн-оформлением ипотеки/рассрочки.
Прототип хранит данные в браузере (localStorage); структура повторяет `db/schema.sql`.

## Роли

- **Главный админ (super)** — заводит строительные компании и их админов, настраивает банковскую интеграцию и продукты для каждой компании, может делегировать компании право заводить другие компании.
- **Админ застройщика (dev_admin)** — заводит ЖК (вручную или импортом Excel), управляет стоком квартир, публикует ЖК (галочка «виден клиентам»), заводит менеджеров и выдаёт им доступ к своим ЖК.
- **Менеджер (manager)** — авторизуется, видит ЖК компании (в т.ч. непубличные), отправляет заявки в банк по прикреплённым ЖК.
- **Клиент (client)** — видит только опубликованные ЖК, оформляет ипотеку онлайн.

## Импорт Excel (сток квартир)

Вкладка «Сток квартир» → «Скачать шаблон», заполните и загрузите через «Импорт Excel».
Колонки: `Блок · Этаж · Комнат · Площадь · Цена · Статус · Картинка`.

## Структура

```
db/schema.sql        схема PostgreSQL для боевого бэкенда
src/App.jsx          приложение (все роли и экраны)
src/storage.js       localStorage-хранилище (замена на API в проде)
public/fonts/        сюда положить лицензионный Museo Sans Cyrl
```

## Что дальше для прода

Прототип — фронт без сервера. Для боевого запуска нужен бэкенд:
- API (Node/NestJS или Go) + PostgreSQL по `db/schema.sql`;
- аутентификация (JWT), хеширование паролей;
- хранилище картинок (S3-совместимое) вместо URL;
- серверный прокси к банкам: сборка `StartMortgage`, приём колбэков `SendOffers` / `UpdateOrderState` (токены банка держать только на сервере).

Развёртывание: фронт — статикой (Vercel/любой хостинг или на ps.kz), API+БД — на VPS ps.kz. Для зоны `.kz` держите хотя бы один NS/хостинг в Казахстане.
